# Spatio-Temporal-Demand-Analytics-of-4.5M-Uber-Pickups-in-NYC-Apache-Spark-
A PySpark pipeline that cleans, stores and analyses 4.5 million NYC Uber pickups. It finds demand patterns, uses K-Means to identify eight demand hotspots, and forecasts hourly demand a day ahead (R² 0.91). It compares storage formats and supports SDG 11 and SDG 9.
